# 서울휠체어럭비 선수단 (공유용)

서울 휠체어럭비 우림맨테크(쿼드)·송파씨젠(오픈) 선수단의 **읽기 전용 공유 화면**이에요.
출석부(월별·연간·선수 평가), 체력테스트, 휠체어 현황을 볼 수 있어요.

- 매월 1일, 편집용 앱의 기록으로 자동 갱신돼요. 화면 오른쪽 위에 몇 월 며칠 기준인지 나와요.
- 연락처·주소 같은 개인정보는 들어 있지 않아요.
- 기록 수정은 편집용 앱에서만 해요.
