# 휠체어럭비 퀴즈 챔피언십 (Wheelchair Rugby Quiz Championship · 2026 WWR 원문 기준)

**2026년 1월 1일 개정판 규정**을 기준으로 다시 만든 학습 사이트입니다. 규정 전문을 조항별로 읽고,
2026 케이스북의 상황을 코트 위 장면으로 보면서 판정을 맞혀봅니다. `index.html` 하나로 동작하며(빌드 없음),
폰 세로 화면을 먼저 기준으로 만들었습니다.

```
academy/quiz/
  index.html               화면 (홈=게임 / 규정 목록 / 조문 / 케이스 목록 / 장별 목록 / 문제 / 결과 / 2026 개정 / 내 기록)
  style.css                밝은 종이 배경 + 게임 카드·코트 장면만 짙은 네이비, 본문 17px
  app.js                   화면 전환·검색·채점·진행 저장·게임 요소(심판 사다리·경험치·배지, localStorage)
  rank-online.js           공유 랭킹·명예의 전당 (Firebase Firestore + 익명 로그인, ?mock=1이면 가짜 서버)
  firebase-config.js       Firebase 웹앱 설정값(비어 있으면 공유 랭킹은 '준비 중')
  firestore.rules          Firestore 보안 규칙(콘솔 규칙 탭에 붙여넣기)
  scene.js                 케이스 장면 재생기 (PixiJS, engine/pixi.min.js·rugby-chairs.js 사용)
  data/rules.json          2026 International Rules 111조 (영문 원문 + 국문)
  data/cases.json          2026 Casebook 퀴즈 217문항 (영문 원문 + 국문)
  data/changes.json        2026 개정 요약 (영문 원문 + 국문)
  tools/parse_rules.py     2021년판 PDF 변환 스크립트(참고용, 더는 쓰지 않음)
  tools/2026/              2026년판 데이터를 만든 스크립트와 국문 번역 원본
```

## 무엇을 2026 기준으로 바꿨나

### 1. 규정 데이터(`data/rules.json`)를 2026 원문으로 재구축
- **정본은 `WWR-Rules-2026.pdf`(April 2026 International Rules, 48쪽)** 입니다. 2021년 국문 번역본은 정본이 아니라
  번역을 재사용하기 위한 참고자료로만 썼습니다.
- 조항 번호·장 구성을 2026 원문 목차 그대로 따랐습니다. **14장 111조**(2021년판은 112조)이고, 조항마다 원문 쪽수를 넣었습니다.
- 2021년판에만 있던 **82조(타임아웃 바이얼레이션)** 가 2026년판에는 없습니다. 그래서 2021년판 83~112조가 2026년판
  82~111조로 한 칸씩 당겨졌습니다(예: 2021년 84조 40초 바이얼레이션 → 2026년 83조). 3~9장처럼 번호가 그대로인 조항은
  그대로 대응됩니다.
- 2021년판 PDF의 인쇄 오류(66조 머리글 누락, 69조 두 번 인쇄)는 2026 원문에는 해당 문제가 없어 **자연히 해소**되었습니다.
  그래서 2026 데이터에는 조항 번호를 바로잡는 보정이 들어가지 않습니다.
- 영문 본문은 PDF에서 조항 단위로 잘라 문단을 복원한 것으로, **요약·의역하지 않았습니다.** 페이지 머리글·꼬리글·쪽번호는 제거했습니다.

### 2. 국문 병기 방식 (숨기지 않고 밝힙니다)

### 4. 케이스 퀴즈(`data/cases.json`)를 2026 케이스북 전체로 확장
- `WWR-Casebook-2026.pdf`(48쪽)에서 케이스 항목 **219개**를 뽑아 **217문항**으로 만들었습니다. 장별 분포는 3장 5 ·
  4장 7 · 5장 7 · 6장 6 · 7장 22 · 8장 48 · 9장 45 · 10장 2 · 11장 36 · 12장 33 · 13장 6입니다.
- 각 문항에는 `caseNo`(2026 케이스북 번호), `page`(2026 케이스북 쪽수), `relatedArticles`(2026 규정 조항 번호),
  국문 문제·보기·해설, **영문 원문**(`questionEn`·`choicesEn`·`explanationEn`)이 들어 있습니다.
- **보기 구성**: 케이스북이 "Is this correct?"로 묻는 항목은 원문 형식 그대로 **옳다 / 옳지 않다** 두 개로 두었습니다.
  "What call should…", "어떻게 처리하는가"처럼 열린 질문은 2~3개의 판정 보기로 만들었습니다.
- **a)·b) 여러 상황을 함께 묻는 케이스**는 한 상황만 골라 단일 정답으로 만들고, 고르지 않은 상황의 답은 해설에 적었습니다
  (예: 3.21.1 → b, 5.36.1 → b, 6.41.1 → A, 6.42.1 → a, 9.78.1 → b, 9.80.2 → b, 11.93.2 → a, 11.97.2 → a).
- **뺀 항목과 이유**
  - `7.58.5`: 원문 PDF에서 질문이 "The coach of Team A requests a"에서 끊겨 있어 뜻이 확정되지 않습니다.
  - `7.56.14`: `7.56.1`과 완전히 같은 케이스가 중복 인쇄되어 있어 한 문항으로만 넣었습니다.
  - `12.10.3`: 케이스북 인쇄가 "12.10.3"으로 잘못 찍혀 있으나 내용상 `12.103.1`이므로 그 번호로 넣었습니다.

### 7. 심판 사다리 · 공유 랭킹 (2026-11-13)
- **등급 = 실제 심판 경로**: 기록심 → 코트심 2급 → 코트심 1급 → (도전! 국제심판) WWR 캔디데이트 → 프로비저널 → 존 레퍼리 → 월드 레퍼리.
  예전 레벨(새내기·지역·국가대표·국제 심판, 누적 정답 수)은 없앴습니다.
- **승급 조건**: 맞힌 '서로 다른 문항' 비율(전체 문항 수에 비례) 15/35/50/65/80/90%를 넘기면 승급 시험이 열립니다.
  시험은 전체에서 섞은 10·20·20·20·30·30문항, 합격선 80·80·80·85·85점. 단계마다 **하루 한 번**, 시작하면 그날 기회를 씁니다.
- **월드 레퍼리**: 월드 시험(30문항)을 최근 5회 중 3회 90점 이상 + 평균 90점 이상 (WWR Evaluation Manual 2025 §7 기준을 줄인 것).
- **국제 시험 언어**: 1급 뒤 한국어/English 선택(내 기록에서 바꿀 수 있음). English 시험은 영어 원문만 나오고 언어 버튼이 숨겨집니다.
  한국어로 월드가 되면 영어 월드 시험을 이어서 볼 수 있고, 영어로 월드가 되면 최고 배지 👑.
- **경험치(랭킹 점수)**: 정답 10점 + 연속 정답 보너스(2점씩, 최대 +10) + 승급 시험 합격 50점. 같은 문항은 하루 한 번만 점수가 붙습니다.
  이번 주 점수는 월요일(기기 날짜)에 0부터. 예전 기록은 '맞힌 문항 × 10점'으로 옮겨 시작합니다.
- **공유 랭킹**: 이번 주 / 역대 / 명예의 전당(월드 도달 순서, 1호·2호…). 닉네임을 넣으면 판이 끝날 때마다 올라갑니다.
  Firestore 구조: `players/{uid}`(누적), `weeks/{YYYY-Www}/players/{uid}`(주간), `hall/{uid_lang}`(한 번 쓰면 못 고침). 예전 '랭킹 코드' 방식은 없앴습니다.
- **홈 맨 위 인사 줄**: "닉네임님, 반가워요" + 대표 배지 + 등급·이번 주 점수·연속일 + 이번 주 순위(상위 50명 안). 닉네임이 없으면 그 자리에 "랭킹 참가" 칸. 큰 제목은 한 줄로 줄였습니다.
- **배지 18종 (SVG로 직접 그린 메달, `badge-art.js`)**: 이름은 영어, 뜻은 작은 한글.
  등급 7(COURT REFEREE II·I, WWR CANDIDATE·PROVISIONAL, ZONE REFEREE, WORLD REFEREE, WORLD LEGEND=영어 월드) ·
  장 마스터 7(SETUP=3~6장, TIMING=7, PLAY=8, VIOLATION=9, FOUL=11, TECHNICAL=12, PENALTY=10·13장, **그 장 문항을 전부 맞혀야** 받음) ·
  스페셜 4(WEEKLY CHAMPION, ON FIRE=7일 연속, PERFECT 10, CASEBOOK MASTER=전체 전부 맞히기).
  가진 배지는 색·빛·반짝임, 못 가진 배지는 회색+자물쇠+진행 막대. 내 기록 맨 위 '대표 배지', 홈에 최근 배지 4개, 배지를 누르면 크게 보기.
  예전 장 '완주' 배지(ch3~ch13, 다 풀기 기준)와 30일 연속은 없애고 새 기준으로 조용히 다시 계산합니다.
- 확인: `?mock=1`로 승급 시험 합격(경험치 +170·+50) → 국제심판 English 선택(영어만 출제) → 월드 English 합격 → 배지·명예의 전당 2호까지 브라우저에서 돌려봤습니다.
  Firebase 프로젝트 `wr-quiz-fceaa`(Firestore 서울 asia-northeast3, 익명 로그인, 규칙 게시)에 연결했고, 쓰기·읽기·남의 문서·범위 초과 쓰기 차단을 실제 서버로 확인했습니다(테스트 기록은 지움).
  아직 없는 것: 강등(월드 90 미만 3연속 → 존). 점수 조작은 보안 규칙의 범위 제한까지만 막습니다.

## 데이터를 다시 만드는 법

`tools/2026/`에 2026년판 데이터를 만든 스크립트를 그대로 넣어 두었습니다. 순서는 다음과 같습니다(작업 폴더 기준 경로).

0. `tools/parse_rules.py` → 2021년 국문 규정집 PDF(대한장애인럭비협회 번역본)를 `build/rules2021.json`으로 다시 뽑습니다.
   국문을 재사용할 때 기준이 되는 표입니다(2026년판 파일을 여기에 쓰면 안 됩니다 — `gen_rules.py`에 2021년판인지 확인하는 검사가 있습니다).
1. `parse_rules2026.py` → `WWR-Rules-2026.pdf`를 쪽별 텍스트로 풀고 조항 단위로 자릅니다.
2. `build_rules_base.py` → 조항·쪽수·문단 구조를 만듭니다(문단이 깨지지 않게 목록 항목을 살립니다).
3. `diffnorm.py` → 2021년판과 2026년판 영문을 숫자·표기 정규화 후 비교해 **실질 변경**만 추립니다.
4. `ko_part1.py`·`ko_part2.py` → 새로 번역한 조항의 국문 원본(이 파일이 국문의 원천입니다).
5. `gen_rules.py` → `data/rules.json` 생성(2021년판 국문 재사용/새 번역, `changed2026`·`changeNote`·`koNew` 부여).
6. `parse_casebook.py` → `split2.py` → 케이스 단위 분리.
7. `ko_cases_*.py` → 케이스 국문 문제·보기·해설 원본.
8. `build_cases.py`, `gen_changes.py` → `data/cases.json`, `data/changes.json` 생성.

스크립트 안의 경로는 이 작업 환경(`/workspace/...`) 기준이므로 다른 곳에서 돌릴 때는 경로만 바꾸면 됩니다.
